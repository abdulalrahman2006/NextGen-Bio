# Team review checklist

Test with at least **three accounts**: a student, an editor and an admin (promote them from Admin > Users, or with SQL).
Use a **private window** to test as a visitor. Tick what works; write down what doesn't (template at the bottom).

## Visitor (not signed in)
- [ ] Home page loads; the hero, latest posts, topics and lab demos are readable
- [ ] Menu works on a phone (Menu button, links open, Close works)
- [ ] /articles lists published posts; topic buttons filter; scrolling loads more
- [ ] Open an article: images, links and embedded YouTube show; comments are readable
- [ ] Like or comment asks you to sign in
- [ ] /search finds words from a title, a post body, a tag and a podcast transcript
- [ ] /podcast: discs rotate with scroll or swipe, click flips a disc, the back is readable
- [ ] /create and /admin send you to the login page

## Student
- [ ] Sign up and sign in; profile page shows your name
- [ ] Edit profile: picture, headline, bio, website save and show on /u/your-id
- [ ] Write an Article: type a title, use Heading, Bold, Link, Image (upload) and Video (YouTube); it looks formatted while you type
- [ ] Write an "Idea or experiment"; the outline button adds the four headings
- [ ] Add up to 5 tags; popular tags can be clicked
- [ ] Submit shows "Waiting for review" in My posts; it is NOT visible to visitors
- [ ] Edit a pending post; edit a published post (it must go back to pending)
- [ ] Podcast post: upload audio, upload a short video, paste a YouTube link, add a cover, timestamps and a transcript
- [ ] Like, comment, delete your own comment; Share copies a link
- [ ] Report a post, a comment and a profile; reporting the same item twice is refused
- [ ] Send feedback normally and anonymously; you cannot read feedback or reach /admin

## Editor
- [ ] /admin opens; Posts shows pending posts; the editor can fix text and Publish
- [ ] Podcast posts show a player (audio, video or YouTube) before approving
- [ ] Reports tab: open the reported item, delete a comment, unpublish a post, dismiss a report
- [ ] Static pages: change the hero text; the home page updates
- [ ] Delete a post (confirmation appears)
- [ ] Editors do NOT see the Users or Feedback tabs

## Admin
- [ ] Users tab: promote and demote a user
- [ ] Feedback tab: messages appear, status changes, delete works; anonymous ones show "Anonymous"

## Drafts, review and notifications
- [ ] Start a post and wait a few seconds: "Draft saved" appears; leave and come back from My posts: "Continue writing" restores it
- [ ] Save draft, then Submit for review; the status changes to "Waiting for review"
- [ ] Editor: open the post in Admin, Request changes with a note; the author sees "Needs changes" and the note on My posts and in the editor
- [ ] Editor publishes; the author sees "New updates" on My posts and a dot on the Account menu
- [ ] Admin posts list: search, status filter, type filter and paging work

## Dark mode, Arabic and sharing
- [ ] The moon/sun button switches the whole site; reload keeps the choice; every page is readable in both modes
- [ ] Write a title, paragraph and comment in Arabic: they line up right-to-left; English text stays left-to-right
- [ ] Upload a large photo in an article: it is shrunk (check it loads fast)
- [ ] Share a published article link in WhatsApp: title, description and picture appear (needs the site to be online)

## Podcast player
- [ ] Tap to play (audio); background colour follows the cover; Pause, Sound, Maximize, Close work
- [ ] Left/Right arrows skip 5 seconds while playing; J and L skip 10; K pauses; M mutes; F full screen
- [ ] Seek bar, Back/Forward 5s, Speed, Go to (type 30:00), Chapters all work
- [ ] Close and reopen: playback resumes where you stopped
- [ ] Transcript panel opens, highlights the current line, click a time to jump, find box filters
- [ ] YouTube and uploaded video episodes play; Share copies a working link
- [ ] Index shows full dates and jumps to the episode

## Phones, browsers and access
- [ ] Phone (iPhone and Android): home, articles, an article, podcast, create
- [ ] Chrome, Firefox, Safari (if available)
- [ ] Everything reachable with the keyboard (Tab, Enter, Escape closes menus and dialogs)
- [ ] Text readable on every page (grey on dark, text over images)
- [ ] Slow connection: pages still usable while the podcast page loads
